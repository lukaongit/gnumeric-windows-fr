# Gnumeric pour Windows – Édition française

Je voulais télécharger Gnumeric pour Windows, car contrairement à LibreOffice, OnlyOffice et Microsoft Office, Gnumeric est plus rapide et ne complique pas les choses, mais il ne semblait pas exister de version disponible pour Windows, alors j'en ai créé une à partir du code source officiel.
Je sais qu'il existe un moyen facile de l'exécuter via WSL, mais natif reste natif, quoi qu'on en dise.

Cette édition est **uniquement en français** : l'interface est verrouillée sur le français (sauf si vous définissez vous-même la variable d'environnement `LANGUAGE` ou `LC_ALL`).

Application **portable** : il suffit de cloner/télécharger ce dépôt et de lancer `bin/gnumeric.exe` – aucune installation n'est nécessaire.

Basée sur Gnumeric **1.12.63-dev** (code source officiel du master en amont).
